# 포에버 착용 효과 · 능력치 점수 자료

FOA 아이템 점수(`FOA_UI/Score.lua`)가 읽는 착용 · 사용 · 적중 시 효과 문장을 게임 파일에서 직접 뽑아 확인한다.

## 착용 효과 문장 뽑기 (게임 빌드 1.60.1.70938, 2026-11-16)

필요한 DB2 (CASC, fileDataID):
`ItemEffect 969941` · `ItemXItemEffect 3177687` · `SpellEffect 1140088` · `Spell 1140089 (koKR)`

1. `koKR` 판 Spell.db2 는 루트에서 로캘 0x4 항목을 골라 꺼낸다 (`s3.py`).
2. Spell.db2 는 오프셋 맵(sparse) 표 → 레코드 안의 글자를 차례로 읽는다 (`sparse.py`).
3. ItemEffect 의 TriggerType 1(착용) · 2(적중 시) → 주문 번호 → 한글 설명 + SpellEffect 값(필드 22 = 기본값)으로
   문장 틀을 모아 아이템 수 순으로 정리한다 (`equip.py` → `equip_templates.json`).
4. 배포한 Score.lua 의 `ParseLine` 으로 전부 읽어 보고, 못 읽은 문장을 아이템 수 순으로 본다 (`cover.py`).

결과 (2026-11-16): 착용 효과가 남은 아이템 861개 중 문장이 있는 544개 → 448개(82%) 해석.
못 읽은 나머지는 수중 호흡 · 지도 표시 · 퀘스트용 · 꾸밈 문장처럼 점수와 상관없는 것.
포에버는 클래식의 능력치형 착용 효과(전투력 · 적중 · 치명 …)를 대부분 초록 능력치 줄로 바꿔서
그쪽은 `GetItemStats` 로 읽는다.

## 능력치 가중치 근거

| 기준 | 출처 |
|---|---|
| PvE (레이드) | Icy Veins 포에버 전문화별 Stat Priority (27개, 2026-11-16) |
| 육성 (레벨업) | Icy Veins 포에버 전문화별 Leveling 공략의 Stats 항목 |
| PvP | Mobalytics 포에버 PvP 공략 (도적 · 전사 · 사냥꾼 · 사제), 나머지는 클래식 PvP 관례 |

- 기준 고르기: 점수 방식 PvP → PvP · 만렙 전 → 육성 · 만렙 → PvE. BIS 판은 보기(육성 · PvE · PvP)마다 그 기준.
- 적중 상한: PvE 근접 8% · 주문 17% / PvP · 육성 근접 5% · 주문 4%.
- 등급 → %: 적중 · 치명 · 가속 · 숙련 · 회피 · 무기 막기 · 방패 막기 (툴팁의 % 를 먼저, 없으면 게임 환산 함수).
